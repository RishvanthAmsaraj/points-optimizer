# Points Optimizer

A web platform that helps users maximize credit card points and miles for travel redemptions.

## Core Value Proposition

Tell us what you have, tell us where you want to go, and we'll build you the exact playbook to get there for the fewest points.

## What Makes Us Different

Unlike existing search tools (Point.me, Roame), we provide **step-by-step optimization playbooks** — not just search results. We bridge the gap between "I have points" and "I know exactly what to do."

## Tech Stack

- **Frontend:** Next.js 14 + React 18 + TypeScript + Tailwind CSS
- **Backend:** Next.js API Routes + Supabase
- **Database:** PostgreSQL (via Supabase)
- **Auth:** Supabase Auth
- **Hosting:** Vercel

## Features (MVP)

- [ ] User onboarding & points inventory
- [ ] Credit card wallet
- [ ] Award flight search
- [ ] Optimization playbook generator

- [ ] Card recommendations
